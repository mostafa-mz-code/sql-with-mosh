# Designing a Database


## Data Modeling

is the process of creating a model for the data that we wanna store in the database.

1. Understand the Requirements: Understand and analyze the business requirements, it might take a bit of time, but it's the most important step.
2. Build a Conceptual Model: build a conceptual model of the business, it involves identifying the entities or things or concepts in the business and the relation between them, a conceptual model is visual representation of these concepts that you use to communicate with the stakeholders. 
3. Build a Logical Model: Is an abstract data model that is independent of the database technology, and just shows you the tables and columns that you need.
4. Build a Physical Model: you build a physical model designed for a specific DBMS technologies. physical model is the implementation of the logical model, data-types, default-values etc...
